# Logic Gates — An Interactive Learning Guide

An interactive web-based simulator and study tool designed for Computer Science students exploring Boolean logic, circuit behaviour, and truth tables. 
Built specifically to support **Cambridge IGCSE Computer Science (0478)**, **O-Level (2210)**, and secondary CS curricula.

---

## ✨ Key Features

- **Live Gate Simulator**: Toggle inputs (0 and 1) in real-time and observe animated signal propagation through dynamic SVG circuits.
- **6 Standard Logic Gates**: Full interactive support for `NOT`, `AND`, `OR`, `NAND`, `NOR`, and `XOR`.
- **Dual Representation**: Shows both standard logic statements (e.g., `X = A AND B`) and Boolean algebra expressions (e.g., `X = A · B`).
- **Live Truth Tables**: Automatically highlights the active input-output row as you toggle switches.
- **Visual Reference Grid**: Quick reference cards with gate symbols, operational descriptions, and standard truth tables.
- **Practice Quiz**: Practice mode that generates random gate inputs and scores your responses with immediate logic feedback.
- **Exam-Style Questions**: 10 Cambridge-style structured questions complete with mark allocations, scenarios, and revealable solutions.
- **Classroom & Projector Friendly**: Scaled typography and layout optimized for presentation displays, featuring an instant Dark/Light theme toggle.
- **Zero Dependencies**: Pure HTML5, CSS3, and modern vanilla JavaScript in a single, lightweight file.
